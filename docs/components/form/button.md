# Button

> **Component:** `components/form/button.twig`

## Purpose

Provides a reusable button/link component that can render either a `<button>` or `<a>` and can resolve a framework route.

## API / Properties

| Property | Required | Default | Description |
|---|---|---|---|
| ``tag`` | Optional | `button` | Rendered element tag. |
| ``class`` | Optional | `btn` | Base CSS class string. |
| ``type`` | Optional | `button` | Button type. |
| ``href`` | Optional | `null` | Direct link href. |
| ``route`` | Optional | `null` | Named framework route to resolve into href. |
| ``route_parameters`` | Optional | `[]` | Parameters passed to `route()`. |
| ``id`` | Optional | `null` | Element id. |
| ``aria_label`` | Optional | `null` | ARIA label. |
| ``title`` | Optional | `null` | Title attribute. |
| ``target`` | Optional | `null` | Link target. |
| ``rel`` | Optional | `null` | Link relationship. |
| ``icon`` | Optional | `null` | Icon class string inserted inside an `<i>` element. |
| ``icon_class`` | Optional | `me-1` | Additional classes on the icon element. |
| ``content`` | Optional | `''` | Button/link text or HTML content. |


## Behavior

When `route` is supplied, it overrides `href` with the result of `route(route, route_parameters)`. Icon markup is generated by the component; callers should provide an icon class string such as `bi bi-check-lg` rather than complete `<i>` markup.

## Example

```twig
{% include 'components/form/button.twig' with {
    tag: 'a',
    class: 'btn btn-primary',
    route: 'tasks.create',
    icon: 'bi bi-plus-lg',
    content: 'New Task'
} %}
```

## Usage

Use `tag: 'button'` for actions and `tag: 'a'` for navigation. Prefer named routes when a framework route should be resolved server-side.

## Notes

When passing `route_parameters`, use the shape expected by the framework route helper; the component defaults to an array.
